Picturesque
===========

Picturesque is an open-source desktop application for culling photos. It
imports photos from scattered folders into a clean, organized library,
groups shots into series, and highlights the best photos using technical
analysis and on-device AI.

.. note::

   Picturesque is in early development. Track progress on the
   `milestones page <https://github.com/denyszorinets/picturesque/milestones>`_.
