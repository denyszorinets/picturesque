Third-Party Data
================

Data bundled with Picturesque, the images in the repository, and their licences.

GeoNames
--------

Place names for photos with GPS coordinates
(:ref:`features-import-places`).

:Source: `GeoNames <https://www.geonames.org/>`_ ``cities500``, admin1 and
   country names
:Licence: `Creative Commons Attribution 4.0
   <https://creativecommons.org/licenses/by/4.0/>`_
:Attribution: Place names from GeoNames (geonames.org), licensed CC BY 4.0.
:In the repository: ``crates/infra/data/geonames-cities500.tsv.gz``,
   rebuilt with ``scripts/build_geonames.py``

Heroicons
---------

The icons of the interface, bundled into the app so it works offline.

:Source: `Heroicons <https://heroicons.com/>`_ by Tailwind Labs, the
   20 px solid set (npm package ``heroicons``)
:Licence: `MIT <https://github.com/tailwindlabs/heroicons/blob/master/LICENSE>`_
:Attribution: Copyright (c) Tailwind Labs, Inc.
:In the repository: imported by ``ui/src/lib/components/Icon.svelte``;
   add an icon there to use it

Images
------

Every image in the repository is CC0, in the public domain, or made by the
project. Photos come from `Wikimedia Commons <https://commons.wikimedia.org/>`_,
whose licence was checked on each file's page.

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Images
     - Source and licence
   * - Screenshots on the website and in these docs
     - The demo library of :repo:`scripts/screenshots/photos.json` (below),
       all CC0; ``build-demo.py`` refuses any other licence.
   * - Test fixtures ``orient_1.jpg`` … ``orient_8.jpg``
     - *Kayaks on a mountain lake* by Matheus Bandoch, CC0
       (:repo:`crates/infra/tests/fixtures/README.md`).
   * - Face fixtures (closed-eye tests)
     - Three CC0 photos and one in the public domain
       (:repo:`crates/infra/tests/fixtures/faces/SOURCES.md`).
   * - Other test images, ``exif.heic``
     - Generated by the tests or by the project.
   * - App icon (:repo:`src-tauri/icon.svg`) and its sizes
     - Made by the project (GPL-3.0-or-later).

The evaluation samples of ``spikes/`` (Wikimedia Commons *Featured
pictures*, mostly CC BY-SA, and CC0 RAW files from raw.pixls.us) are
downloaded by their scripts and never committed.
